# Svg2Pattern

This script helps to convert .svg into your specific pattern.


# Usage

Run:

```bash
python3 main.py <MY_SVG_FILE>
```

Example:

```bash
python3 main.py linux-svgrepo-com.svg >> resul.txt
```

Then copy result -> `sample.glsl` -> SVG() function.
